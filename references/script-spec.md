# 讲稿规格

这份文件定义「讲透」的可操作标准。它管三件事：一集怎么分段、一段怎么展开、一句怎么说。

写作前提：观众刚高考完，先修课基本忘光。凡是稿子里没重建过的，都算没讲。

---

## 一、三层结构

| 层 | 单位 | 长度 | 作用 |
| --- | --- | --- | --- |
| 集 | 一集 | 35–55 分钟 | 一个闭环，结束时能独立做一件事 |
| 单元 | 讲解单元 | 5–12 分钟 | 一个知识点，走完六拍 |
| 拍 | 一段 | 30–90 秒 | 一个动作：提问、演示、推导、检验 |

不要用「页」当单位。页是画面的事，讲稿按单元写，分镜再把单元切页。

---

## 二、一个讲解单元的六拍

顺序固定，缺拍要写明理由。

**1. 钩子（30–60 秒）**
先给一个用旧办法解决不了的具体问题。不要从定义开始。

> 反例：这节课我们学习自相关函数。自相关函数的定义是……
>
> 正例：上节课我们算了噪声的平均功率。但如果我问你「这个噪声变化得快不快」，平均功率答不了——两个功率一样的噪声，一个平缓、一个剧烈，听起来完全不同。要回答这个问题，得换一个量。

**2. 直觉（1–3 分钟）**
用看得见的东西建立画面：两条样本函数、一张图、一个日常类比。类比要能撑到后面，不要用完就丢。

**3. 形式化（2–4 分钟）**
从直觉过渡到符号。每个符号第一次出现，念一遍、说清它代表什么、为什么需要它。

**4. 例题（3–5 分钟）**
走五段式（见第四节）。例题只用一个新方法，不要复合三个知识点。

**5. 检验（30–60 秒）**
给一个判断题或预测题，先让观众想，再揭晓。停顿写进分镜，不要口播"大家想一想"就滑过去。

**6. 变式（1–2 分钟）**
改一个条件，问会发生什么。变式是给下一拍埋钩子，也是检验"真懂还是背下来"的唯一方式。

---

## 三、推导四槽位

每一步推导单独一行。三个等号挤在一行的，拆成三行。

每行四个槽位，缺一不可：

| 槽位 | 写什么 | 长度 |
| --- | --- | --- |
| ① 这一行 | 公式或语句本身 | 一行 |
| ①′ 念法 | 念给耳朵听的人话，包括符号怎么读 | 一句 |
| ② 为什么可以 | 用了哪条规则、这条规则为什么成立、代入了什么 | 1–2 句 |
| ③ 继承了什么 | 上一行的哪部分被搬下来、哪部分被改写 | 一句 |

示例：

```
①  R_X(τ) = E[X(t)X(t+τ)]
①′ 自相关函数，等于 X 在 t 时刻的取值，乘上它在 t 加 τ 时刻的取值，再取数学期望。
②  这里能写成期望，是因为固定 τ 之后，X(t)X(t+τ) 仍然是一个随机变量，
    而随机变量的期望是有定义的。前提是这个二阶矩存在。
③  起点：题目给了零均值、宽平稳两个条件，所以乘积的期望只和 τ 有关。
```

**四条硬规则**：

- 纵向：上一行必须推得出下一行。写不出 ③ 就是跳步。
- 横向：这一行自己必须立得住。符号定义过、条件满足、分母不为零。
- 每个等号都要有理由。「整理得」「化简得」不算理由，要说是配方、还是提取公因式。
- 第一行的 ③ 写「起点：题目给的什么」，不要空着。

## 四、例题五段式

1. **这题在问什么**
   把符号翻成人话。标出已知、所求、隐含条件。

2. **为什么用这个方法**
   指出题干里哪个词在提示。不是"因为这是第五章"，是"因为题目说宽平稳，所以相关函数只依赖 τ"。

3. **逐行推导**
   四槽位。卡点处插一个「你来判断」：给三个候选下一步，让观众选。

4. **结果检验**
   至少两项：
   - 量纲对不对
   - 边界对不对（τ=0、τ→∞、参数取 0 或 1）
   - 物理意义对不对（功率非负、谱非负、方差 ≥ 0）
   - 特例能不能退化成熟知结论

5. **变式**
   改一个条件，给出答案与关键差异。变式要和原题"只差一个地方"，否则是另一道题。

## 五、密度阈值

`check_script.py` 按这些阈值检查。阈值是下限，不是目标。

| 指标 | 阈值 | 为什么 |
| --- | --- | --- |
| 中文旁白语速 | 200–280 字/分钟 | 低于 200 是念稿，高于 280 听不清 |
| 每 10 分钟检查点 | ≥ 1 | 超过 10 分钟没有互动，注意力必掉 |
| 每 500 字「为什么/因为/依据」 | ≥ 2 | 低于这个数，基本是在报结论 |
| 连续陈述无提问 | ≤ 4 分钟 | 口播超过 4 分钟，观众开始走神 |
| 单句长度 | ≤ 60 字 | 中文口播超过 60 字，一口气念不完 |
| 每段新术语 | ≤ 2 | 一段塞三个新词，等于都没讲 |
| 禁用词 | 0 | 「显然」「易知」「不难看出」「众所周知」「不再赘述」 |

先修重建不计入密度：一个 3 分钟的先修复习，可以没有检查点。

## 六、语言规则

**口播，不是书面语。**

- 用短句。一句话一个动作。
- 少用「其」「该」「上述」「综上所述」。
- 允许口语连接：「那」「也就是说」「注意这里」「先别急着算」。
- 不写「大家想一想」然后立刻给答案。要停，停顿写进分镜。

**术语第一次出现，三步：**

1. 先说现象：「两个不同时刻的取值，会有某种关联」。
2. 再给名字：「这种关联，我们叫它自相关」。
3. 最后给符号：「记作 R_X(τ)」。

顺序不能倒。先给符号再解释，观众会把符号当成新东西背下来。

**符号读法表**（写进 `content/glossary.md`，全课统一）：

| 符号 | 读法 | 备注 |
| --- | --- | --- |
| E[·] | 数学期望 / 均值 | 第一次出现说全称 |
| R_X(τ) | R 下标 X，τ | τ 读"套" |
| S_X(ω) | S 下标 X，ω | ω 读"欧米伽" |
| X(t) | 大 X，t | 强调是大写，表示随机变量 |
| x(t) | 小 x，t | 强调是小写，表示一次实现 |
| ⊗ | 卷积 | 读"卷积"不读符号 |
| ∼ | 服从 | "X 服从高斯分布" |

大小写 X/x 的区别，是随机信号分析第一个必须讲清的地方。样本函数和随机变量混淆，后面全乱。

## 七、分镜表

`shots.yaml` 每条的字段：

```yaml
- id: EP01-S012
  unit: U3                 # 属于哪个讲解单元
  narration_ref: script.md#L120-L128
  duration: 42             # 秒
  visual: formula          # formula | plot | diagram | code | text | mixed
  content:
    formula: "R_X(τ)=E[X(t)X(t+τ)]"
    highlight: ["E[...]", "τ"]
  caption: "自相关函数，衡量同一个过程隔 τ 秒后还像不像自己"
  pause_after: 2.0         # 秒，用于思考或转场
```

规则：

- 一个 shot 只讲一件事。旁白里出现两个新对象，就拆两个 shot。
- `highlight` 必须能对应到画面上的具体元素，不能写"整段"。
- `pause_after` 只在检查点、关键结论、转场使用，不要每句都停。

## 八、反例与改法

### 反例（不合格）

> 自相关函数定义为 R_X(τ)=E[X(t)X(t+τ)]。它有以下性质：R_X(0) 等于平均功率，R_X(τ) 是偶函数，|R_X(τ)| 小于等于 R_X(0)。下面看一道例题。

问题：定义直接给、性质直接列、没有动机、没有推导、没有检验。观众只能背。

### 改法

> 上节课算的平均功率，是一个数。它告诉你这个噪声"有多强"，但没告诉你"变多快"。
>
> 看这两条曲线（画面：两条功率相同的噪声，一条平缓、一条剧烈）。它们的平均功率一样，可是听起来完全不是一个东西。差别在哪？在于"隔一段时间之后，还像不像自己"。
>
> 平缓的那条，隔 0.1 秒再看，值还差不多；剧烈的那条，隔 0.1 秒已经完全是另一个数了。
>
> 所以我们需要一个量，专门衡量"隔 τ 秒之后，还像不像自己"。这个量叫自相关函数。
>
> 怎么算"像不像"？最直接的办法，是把 t 时刻的值和 t+τ 时刻的值乘起来，再对所有可能的实现取平均。乘起来大，说明同号、同方向；乘起来小，说明没关系。
>
> 写成式子就是 R_X(τ)=E[X(t)X(t+τ)]。（推导四槽位）
>
> 先看 τ=0 会怎样？（停 3 秒）R_X(0)=E[X²(t)]，正好是平均功率。也就是说，平均功率只是自相关在 τ=0 处的一个特例。这个检验说明我们没定义错。

差别不在字数，在于：**动机 → 画面 → 问题 → 定义 → 检验**，每一步都接得上。
